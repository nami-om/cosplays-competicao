# cosplays-competicao

Site unicamente construido em JavaScrit, com base em fichas de inscricáo para cosplayers que tem o desejo de competir em tal evento. 

Levando em conta que a criadora tem muita convivencia nesse ramo e dominancia no assunto escolheu esse tema em especifico para se aprofundar achando que seria divertido mexer com o assunto de forma criativa. 

Ele pede inicialmente que o individuo dê suas informaçoes para iniciar o cadastro jutamente com o cosplay que estará sendo usado para competir, logo após isso, o programa fará uma analise onde verá a veracidade da roupa em uso para a referencia (personagem + midia informada), caso seja canonico estará liberado para competir e em caso negativo nao subirá ao palco.
